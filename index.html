📊 About This Dashboard

This is a competitive price intelligence tool for Tablet Mexico, tracking the weekly retail prices of tablet models across five channels — Official Site, Liverpool, Elektra, Coppel, and Telcel — in the Mexican market. Data is stored in data.js alongside the dashboard file. No internet connection or server is needed to view it.

Brand color coding: Xiaomi / Redmi / POCO · Samsung · Lenovo · Honor · Huawei

📑 Tab Guide

Recent Snapshot

Shows the current week's promotional prices for every tracked model across all channels. Each price cell shows the promotional price, the channel's RRP in light gray below it, and the % discount. A competitor price is highlighted in red when it undercuts Xiaomi's best price in the same series and channel. The 4-week sparkline in the last column shows recent price movement.

Historical Data

A full price history table — rows are product-channel combinations, columns are weeks. Use the Channel and Week range filters (visible on this tab) to narrow the view. ▼ green means the price dropped vs the previous week; ▲ red means it rose. The highlighted column is the currently selected week.

Export

The ↓ Export button at the top right downloads the current Historical Data view (respecting all active filters) as a formatted .xlsx file. Prices are stored as plain numbers so Excel can sort and chart them.

⚙️ How to Update Each Week

1
First-time setup only

Install Playwright: pip install playwright then playwright install chromium. You only need to do this once.

2
Run the update script

Open a terminal in the Pad Competition folder and run python update.py. Confirm the week label (e.g. W23-2026) — it defaults to the next week automatically.

3
Watch the scraper run

The script opens a headless browser and visits each product URL. Successfully fetched prices are shown with → $price. Anything it couldn't get is queued and shown at the end.

4
Handle manual entries

After scraping finishes, you're prompted for any prices that couldn't be fetched automatically — one by one with the product name, channel, RRP, and link shown. Press Enter to skip a product, or - to mark it as unavailable.

5
Refresh the dashboard

data.js is updated automatically. Just reload index.html in your browser — the new week column appears immediately.

💡 Tip: run python update.py --dry-run first to test the scraper without saving anything. All prices are fetched and shown but data.js is not modified.

📁 文件夹内容

index.html看板主文件，用任意浏览器打开即可，无需服务器。
data.js所有价格数据（JS 格式），由 update.py 每周自动生成。请勿手动编辑。
historical_data.xlsx价格追踪主文件，含四个工作表（S85、S84、S83、S82），行为产品渠道，列为各周。是数据的唯一来源。
update.py每周更新脚本，使用 Playwright 抓取价格，无法自动获取的价格通过手动输入补全，最终将新一周数据写入 data.js。

⚙️ 每周更新流程

1
首次配置（仅需一次）

安装 Playwright：pip install playwright，然后运行 playwright install chromium。

2
运行更新脚本

在 Pad Competition 文件夹中打开终端，执行 python update.py。确认周标签（如 W23-2026），脚本会自动推算下一周作为默认值。

3
等待自动抓取

脚本启动无头浏览器，逐一访问每个产品链接。成功获取的价格显示为 → $价格，无法获取的加入队列，在最后统一处理。

4
手动补录价格

抓取完成后，脚本逐一提示需要手动录入的产品（显示产品名、渠道、建议零售价和链接）。直接回车跳过，输入 - 标记为不可用。

5
刷新看板

data.js 已自动更新，在浏览器中刷新 index.html 即可看到新一周数据。

💡 提示：可先运行 python update.py --dry-run 测试抓取效果，价格会被获取并展示，但不会修改 data.js。

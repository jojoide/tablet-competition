📊 About This Dashboard

This is a competitive price intelligence tool for Tablet Mexico, tracking the weekly retail prices of tablet models across five channels — Official Site, Liverpool, Elektra, Coppel, and Telcel — in the Mexican market. Price data is embedded directly inside index.html, so no internet connection or server is needed to view it.

Brand color coding: Xiaomi / Redmi / POCO · Samsung · Lenovo · Honor · Huawei

📑 Tab Guide

Recent Snapshot

Shows the selected week's prices for every tracked model across all channels. Each cell shows the promotional price, the channel's RRP in light gray below it, and the % discount from RRP. A competitor price is highlighted in red when it undercuts Xiaomi's best price in the same series and channel.

Historical Data

A full price history table — rows are product-channel combinations, columns are weeks. Use the Channel and Week range filters to narrow the view. ▼ green means the price dropped vs the previous week; ▲ red means it rose. Click any price to open the product page.

Export

The ↓ Export button at the top right downloads the current Historical Data view (respecting all active filters) as a formatted .xlsx file.

📁 Folder Contents

index.htmlThe dashboard — open in any browser. All price data is embedded inside. This is the only file you need to upload to GitHub Pages.
data.jsPrice data as a standalone JS file. Kept in sync with index.html by update.py and parse_excel.py.
historical_data.xlsxMaster price tracker. Four sheets (S85, S84, S83, S82). Rows = product-channel, columns = weeks. Edit this when adding products, changing RRP, or correcting past data.
update.pyWeekly update script. Opens each product page in a browser so you can read and enter the price, then saves the new week to data.js and index.html.
parse_excel.pyRebuilds all data from historical_data.xlsx. Run this whenever you edit the Excel file (adding products, fixing RRP, changing memory). Preserves any weeks added by update.py that aren't in the Excel yet.
run_friday.batBatch file used by Windows Task Scheduler to run update.py automatically each Friday.

⚙️ How to Update Each Week

1
First-time setup only

Install Playwright: pip install playwright then playwright install chromium. You only need to do this once.

2
Run the update script

Open Command Prompt, navigate to the folder, and run python update.py. Type the week label when prompted (e.g. W25-2026).

cd "C:\Users\Briony Zhao\iCloudDrive\Desktop\Xiaomi\GTM pages\Pad Competition"
python update.py

3
Enter prices in the browser

A browser window opens and navigates to the first product page. Read the current price on screen, type it into the terminal, and press Enter. The browser automatically moves to the next product page. Press Enter without typing to skip a product, or type - to mark it as unavailable.

4
Review and confirm

After all products, the browser closes and a review table is shown with each new price alongside last week's price and the % change. Prices that changed by ≥20% are flagged with ⚠️. Type edit 5 to correct row 5, or press Enter to confirm and save.

5
Upload to GitHub

data.js and index.html are saved automatically. Upload index.html to your GitHub Pages repository — it is fully self-contained.

💡 To re-enter prices for a past week, run python update.py, type the existing week label (e.g. W24-2026), and confirm the overwrite prompt.
💡 If you edit historical_data.xlsx (products, RRP, memory), run python parse_excel.py afterwards to sync the dashboard. Run python update.py --dry-run to test entry without saving.

📁 文件夹内容

index.html看板主文件，用任意浏览器打开即可，无需服务器。价格数据已内嵌其中，是上传至 GitHub Pages 的唯一文件。
data.js独立的价格数据文件，由 update.py 和 parse_excel.py 同步维护。
historical_data.xlsx价格追踪主文件，含四个工作表（S85、S84、S83、S82），行为产品渠道，列为各周。新增产品、修改建议零售价或修正历史数据时请编辑此文件。
update.py每周更新脚本。自动打开每个产品页面供查阅，输入价格后自动跳转至下一个，最终将新一周数据写入 data.js 和 index.html。
parse_excel.py从 historical_data.xlsx 重建全部数据。编辑 Excel 文件后（新增产品、修改建议零售价、调整内存规格）运行此脚本同步看板。已通过 update.py 录入但尚未写入 Excel 的周数据将被保留。
run_friday.bat供 Windows 任务计划程序每周五自动运行 update.py 的批处理文件。

⚙️ 每周更新流程

1
首次配置（仅需一次）

安装 Playwright：pip install playwright，然后运行 playwright install chromium。

2
运行更新脚本

打开命令提示符，进入文件夹后运行 python update.py，根据提示输入周标签（如 W25-2026）。

cd "C:\Users\Briony Zhao\iCloudDrive\Desktop\Xiaomi\GTM pages\Pad Competition"
python update.py

3
在浏览器中录入价格

浏览器窗口自动打开并跳转至第一个产品页面。在页面上查看当前价格，在终端中输入并回车。浏览器随即跳转至下一个产品页面。直接回车跳过，输入 - 标记为不可用。

4
审核并确认

所有产品录入完毕后，浏览器关闭，终端显示审核表格，包含新价格、上周价格及变动幅度。变动幅度 ≥20% 的条目将以 ⚠️ 标记提醒核实。输入 edit 5 可修改第5行，直接回车确认保存。

5
上传至 GitHub

data.js 和 index.html 已自动保存。将 index.html 上传至 GitHub Pages 仓库即可——文件完全自包含，无需其他依赖。

💡 如需重新录入某历史周的价格，运行 python update.py，输入已有的周标签（如 W24-2026），并确认覆盖提示即可。
💡 修改 historical_data.xlsx 后（产品、建议零售价、内存规格），运行 python parse_excel.py 同步看板。可用 python update.py --dry-run 测试录入流程而不保存数据。
